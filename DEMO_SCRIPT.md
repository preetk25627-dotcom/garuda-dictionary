# Demo Video Script — Garuda Dictionary

**Target length:** 2–3 minutes  
**Format:** Screen recording with your voice. Keep the browser window and app interactions visible.

## Recording plan

### 0:00–0:15 — Introduction
"Hi, this is Garuda Dictionary, a lightweight Hindi dictionary web app. It helps users explore Hindi words with Roman and English search support."

### 0:15–0:45 — Search
- Open the app.
- Search for a Hindi word such as `पानी`.
- Clear the search and try a Roman transliteration or English query supported by the app.
- Point out the matching results.

Narration: "Users can search using Hindi text, Roman text, or English text, making the dictionary easier to access."

### 0:45–1:15 — Filters and word details
- Apply the available part-of-speech filter(s).
- Open a word's detail dialog.
- Show the information displayed for that entry.

Narration: "The filters help narrow the list, and selecting a word opens its detailed entry."

### 1:15–1:40 — Saved words
- Save a word.
- Switch to the saved-words view/filter.
- Remove it from saved words.

Narration: "Saved words are stored locally in the browser, so the user can revisit a personal shortlist."

### 1:40–2:10 — Responsive layout and accessibility
- Resize the browser to a narrow/mobile width, or use browser device emulation.
- Show the layout at mobile width.
- Demonstrate the keyboard search shortcut if available.

Narration: "The interface adapts to smaller screens and includes keyboard-friendly interaction."

### 2:10–2:30 — Close
"That was Garuda Dictionary. The source code, setup details, and project notes are available in the public GitHub repository. Thank you."
